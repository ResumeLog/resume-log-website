# Product Hunt launch assets

Gallery images (1270×760 @2x) and a 35 s, 1080p demo video, built from the real product screenshots in `src/assets/screens`.

| File | What |
| --- | --- |
| `out/1-hero.png`, `out/2-capture.png`, `out/3-ats-check.png` | Gallery images |
| `out/resumelog-demo.mp4` | Demo video with sound (H.264 1920×1080 30 fps, AAC 48 kHz, −16 LUFS) — upload this one |
| `out/resumelog-demo-silent.mp4` | Same video without audio |
| `out/youtube-thumbnail.png` | YouTube thumbnail (1280×720 @1.5x = 1920×1080) — `thumbnail.html`, `render-thumbnail.mjs` |
| `gallery.html` (`?n=1..3`), `video.html`, `shared.css` | Sources — open in Chrome to preview |

## Regenerate

Needs Node, Playwright 1.55 and ffmpeg. Set the Chromium path inside the scripts if yours differs.

```sh
node render-gallery.mjs "$PWD"
node render-video.mjs "$PWD" full ./frames      # use `preview` for 8 sample frames
ffmpeg -framerate 30 -i frames/f-%05d.jpg -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -movflags +faststart out/resumelog-demo-silent.mp4
python soundtrack.py out/soundtrack.wav        # original synthesised music + SFX, needs numpy
ffmpeg -i out/resumelog-demo-silent.mp4 -i out/soundtrack.wav -map 0:v -map 1:a -c:v copy -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 -c:a aac -b:a 192k -movflags +faststart out/resumelog-demo.mp4
```

`video.html` is a seekable timeline (`window.seek(t)`), so every frame is deterministic.

The soundtrack is generated by `soundtrack.py` (no samples or third-party music), so YouTube won't raise copyright claims. Chord changes and sound effects are timed to the `video.html` scene cuts — keep them in sync if the timeline changes.
